## 定义

大语言模型（Large Language Model, LLM）是一种基于 [[Transformer架构]] 的深度神经网络，
通过在海量文本数据上进行自监督学习，获得理解和生成人类语言的能力。
通常参数规模在数十亿到数万亿之间。

## 核心原理

1. **预训练（Pre-training）**：在海量文本上做"下一个 token 预测"（next token prediction），
   学习语言的统计规律、事实知识、推理模式
2. **指令微调（Instruction Tuning / SFT）**：用高质量问答对话数据调整模型，
   使其学会"遵循指令"
3. **人类反馈强化学习（RLHF）**：通过人类偏好标注训练奖励模型，
   再用强化学习使模型输出更符合人类期望
4. **推理增强**：2024 年起，通过"思维链"（Chain-of-Thought）、
   推理时间缩放（test-time compute scaling）等手段大幅提升复杂推理能力

## 关键能力

- **语言生成**：文本续写、摘要、翻译、创意写作
- **知识问答**：基于训练语料中的事实知识回答问题
- **代码生成**：理解和生成多种编程语言的代码
- **推理**：数学推导、逻辑分析、多步规划（2024 年后显著提升）
- **工具使用**：调用外部 API、搜索引擎、代码解释器（Agent 形态）

## Scaling Laws（规模定律）

2020 年 OpenAI 提出：模型性能随 **参数量、数据量、计算量** 三个维度
的增大而可预测地提升。这一定律指导了整个行业"更大即更好"的路线。

但 2024-2025 年出现新趋势：
- **数据墙**：高质量文本数据接近耗尽
- **推理时缩放**：不增大模型，而是让模型在推理时"思考更久"
- **小模型能力追赶**：70B 模型通过更好的数据和训练策略，性能逼近 405B 模型

## 关键挑战

| 挑战 | 说明 |
|------|------|
| 幻觉（Hallucination） | 模型会自信地编造不存在的事实 |
| 对齐（Alignment） | 让模型行为符合人类价值观和意图 |
| 成本 | 训练和推理的算力/能源消耗巨大 |
| 评估 | 传统基准被"刷爆"，缺乏可靠的评测体系 |
| 安全 | 滥用（诈骗、虚假信息）、越狱（jailbreak）风险 |
