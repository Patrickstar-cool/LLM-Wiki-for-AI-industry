# 企业 AI Agent 治理 2026

> VentureBeat Research 于 2026 年 6 月对 573 名企业领导者进行五份平行调查的核心发现：**企业在控制措施就绪之前就部署了 AI Agent——而且它们知道这一点。**

## 五大控制层

| 控制层 | 职能 | 关键发现 |
|--------|------|----------|
| **编排（Orchestration）** | 协调多步 Agent 工作 | 71% 企业承认其"Agent"中仅 1/4 能自主完成多步任务；大部分是套 Agent 标签的聊天机器人 |
| **评估（Evals）** | 判断 Agent 工作质量 | 2/3 企业允许 Agent 仅凭自动化评估结果就推送生产变更；仅 5% 完全信任这些评估 |
| **安全与身份（Security & Identity）** | 控制 Agent 权限 | 69% 企业让 Agent 共享凭证；共享凭证的企业安全事件率 63.5% vs 独立身份 40.9% |
| **基础设施与计算（Infra & Compute）** | 追踪 AI 算力成本 | 8 成以上自运营 GPU 企业利用率 ≤ 50%；仅 44% 严格追踪 AI 计算成本与回报 |
| **上下文层/RAG（Context Layer）** | 供给 Agent 的业务数据 | 57% 企业过去 6 个月曾因业务上下文缺失/不一致导致 Agent 给出自信但错误的答案 |

## 核心发现

### 1. 大多数"Agent"其实是聊天机器人

**71% 的企业**表示只有不到 1/4 的已部署"Agent"能独立完成多步任务；仅 10% 的企业说真正的 Agent 占多数。被调查者 81% 是公司 AI 采购的推荐者或决策者——他们最有资格判断。

### 2. 自主权跑在了信任前面

- **2/3 企业**已经或正在 12 个月内实现 Agent 在无人工审核的情况下推送生产变更
- 仅 **5%** 完全信任做出该决策的评估结果
- **一半企业**过去一年内曾有一个 Agent 通过内部评估后引发面向客户的故障

### 3. 凭证共享 = 更高的安全风险

- 共享凭证的企业发生过安全事件或险情的比例：**63.5%**（74 家中 47 家）
- 每个 Agent 拥有独立身份的企业：**40.9%**（22 家中 9 家）
- 差距：**22.6 个百分点**

### 4. GPU 大部分时间在闲置

- **80%+** 自运营 GPU 的企业利用率 ≤ 50%
- 仅 **44%** 严格追踪 AI 算力的实际成本与回报

### 5. 数据治理滞后于 Agent 扩展

- **57%** 企业曾因业务上下文缺失/不一致导致 Agent 自信地给出错误答案
- 大部分企业不止发生一次

## 市场信号：尚无锁定型霸主

| 控制层 | 12 月内计划更换/新增供应商 |
|--------|---------------------------|
| 编排 | **68%**（34% 季度内） |
| 评估 | 57-68% |
| 安全与身份 | 57-68% |
| 基础设施 | 57-68% |
| 上下文/RAG | 57-68% |

默认选择是大型 AI 平台自带的工具，但所有层级都有显著的切换意愿。编排层的切换意愿最高。

## 方法论

五份平行调查于 2026 年 6 月通过 VB Pulse 开展：Agentic Orchestration（101）、Agent Reliability & Evals（157）、Agentic Security & Identity（107）、AI Infrastructure & Compute（107）、Context Layers / RAG（101）。共 **573 名**合格受访者，均来自 100+ 员工的组织。样本为自选，部分发现应视为方向性信号。
