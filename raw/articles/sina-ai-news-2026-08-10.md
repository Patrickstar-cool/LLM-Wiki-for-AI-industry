# 新浪 AI 热点小时报 2026-08-10：DeepSeek 拟提价 + 硅谷 200 家初创联名信

- 来源：https://k.sina.com.cn/article_7857201856_1d45362c001908iuns.html

## DeepSeek 拟整体上调 API 价格（8/6 公告）

- 中信建投 8/10 研报：**DeepSeek 于 8 月 6 日公告计划近期整体上调 API 服务定价，预计涨幅较大，具体方案待正式通知**
- 此前 DeepSeek 已引入峰谷定价机制：高峰时段 API 价格为平峰时段的 2 倍
- 背景：大模型竞争正从单纯模型能力比拼向 Agent 及商业化应用加速延伸（阿里 Qwen3.8-Max 同步推进企业级 Agent「千问办公」公测）
- 解读：在全球价格战背景下 DeepSeek 逆势提价，显示其用户规模与需求弹性已足以支撑涨价

## 硅谷近 200 家科技初创企业联名信

- 由美国硅谷近 200 家科技初创企业组成的行业协会联名致信美国政府，**明确反对限制本土企业使用中国开放权重 AI 模型**
- 信中指出：「美国开发者需要持续使用全球范围内现有的开放模型」
- 人民日报和音评论：中国开源模型正从全球产业版图的「可选项」，成为众多海外开发者开展技术创新的「必选项」
- 这是美国企业基于现实商业利益的理性选择，折射全球产业界对中国开源 AI 的广泛认可
