# The 2025 AI Agent Index: Documenting Technical and Safety Features of Deployed Agentic AI Systems

**arXiv ID:** 2602.17753v2 | **Venue:** ACM FAccT 2026

## 概述

该 Index 记录了 30 个最先进 AI agent 的起源、设计、能力、生态系统和安全特性。信息来源包括公开信息和与开发者的邮件通信。

## 核心发现

- **透明度差异巨大** — 各 agent 开发者的透明度参差不齐
- **安全信息匮乏** — 大多数开发者分享的安全、评估和社会影响信息很少
- 涵盖三类 agent：聊天类（如 ChatGPT Agent）、浏览器类（如 Perplexity Comet）、企业类（如 HubSpot Breeze Agents）
- 在线版本：https://aiagentindex.mit.edu

## 研究意义

为研究人员和政策制定者提供了系统性的 agent 生态图谱，揭示了当前 agent 部署中透明度和安全评估的重大缺口。
